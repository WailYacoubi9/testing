** Modele Theorique
#+BEGIN_SRC
T_total = T_init + T_seq + T_comm + T_calc + T_agg

Avec:
- T_init(n) = alpha * n + beta
- T_seq(S) = T_parse + S / V_split
- T_comm(S, n, mode) = n * (L + S/n / BW)  [SCP] ou L [NFS]
- T_calc(S, n) = S * density / (n * V_wc) + n * (L_rmi + o_rmi)
- T_agg = constante
#+END_SRC

| L_scp     | Latence SCP (ms)               | run_transfer_benchmark.sh |

| L_nfs     | Latence NFS (ms)               | run_transfer_benchmark.sh |
| BW_nfs    | Bande passante NFS (MB/s)      | run_transfer_benchmark.sh |
| V_wc      | Vitesse wordcount (lignes/s)   | run_wordcount_benchmark.sh|
